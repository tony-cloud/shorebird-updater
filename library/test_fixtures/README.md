These fixtures contain test data only. `response_test_private.der` is a throwaway
RSA private key intentionally checked in for nonce-dependent protocol tests; it
must never be used by a server or app. `response_test_public.der` is its PKCS#1
public half.

`interpreter_envelope.json` was generated by the production Dart
`open_aot_patch_tools` `linkArtifacts` and `encryptArtifact` functions, using
`forceFullSnapshot: true`, plaintext `test-only interpreter bytecode payload`,
AES test key `000102030405060708090a0b0c0d0e0f101112131415161718191a1b1c1d1e1f`,
and nonce `000102030405060708090a0b`. The updater tests wrap it with the production
Rust patch maker using an empty diff base, then reconstruct it with a nonempty
native application base. AES decryption is the interpreter runtime's job.

`server_response_v1.json` was produced by the Go server's real HTTP integration
`TestAuthenticatedPatchCheckHTTPCoversDeliveryAndRollbackWithNonce`.
`server_response_public.der` is the same fixture's PEM key converted to PKCS#1
DER. The Rust test verifies both its signed response and legacy artifact-hash
signature, providing a Go-to-Rust protocol compatibility check.
